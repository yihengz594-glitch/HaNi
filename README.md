# 拼豆图纸生成器 MVP

这是一个可以直接导入微信开发者工具的原生微信小程序原型。

## 当前功能

- 从相册或相机选择图片
- 选择 16、24、32、48 格图纸
- 将图片裁成正方形并转换为拼豆颜色网格
- 使用 MARD 221 色板进行颜色匹配，并显示具体色号和数量
- 点击网格中的豆子，循环切换颜色
- 将图纸导出为 PNG 并保存到相册

## 导入方法

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前目录下的 `拼豆小程序MVP`。
4. 如果工具提示 AppID，请先使用测试号；以后发布时换成你自己的小程序 AppID。
5. 在真机预览测试图片选择和保存相册功能。

## 当前边界

当前仍是本地 MVP；已增加会员中心、套餐展示、最近生成本机缓存和兑换入口。支付默认处于安全测试模式，只有配置独立 HTTPS 服务端并将 `pages/index/membership-config.js` 切换为 `live` 后才会调用 `wx.requestPayment`。真实会员状态、订单和兑换码必须由服务端校验，具体字段与接口见 `server/README.md`。当前使用公开 MIT 数据源中的 MARD 221 色板；HEX/RGB 只是屏幕近似值，实际颜色以购买品牌和批次为准。

## 色板来源

色板取自 [maxcleme/beadcolors](https://github.com/maxcleme/beadcolors) 固定提交 `29229889` 的 `raw/mard.csv`，使用其中 A、B、C、D、E、F、G、H、M 九个系列，共 221 个色号。上游采用 MIT License；MARD 名称和实际色彩仍以购买品牌、色卡及批次为准。
