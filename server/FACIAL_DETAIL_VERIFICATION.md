# 小尺寸五官保留验证 · 2026-10-02

## 实际原因与改动

用户毕业女孩JPEG（997×1280）在旧分类中落入照片分支。原生像素平坦率90.97%，但前16种粗色桶只覆盖74.00%，不满足旧卡通要求的78%。照片分支取整个格子的通道中位色，细棕色嘴线被多数肤色覆盖。

仅修改 `shared/small-pattern-engine.js`：高平坦度、较丰富配色的卡通可以进入卡通分支；卡通采样7×7提高到11×11。保留肤色等亮区内有跨度、亮度差和两侧亮区证据的少量细线。不依据人脸坐标重画、不新增格数、不全局膨胀暗色、不修改MARD或照片采样。分类微调可能影响满足条件的其他平滑图，不能承诺适用于每种照片。

真实图片52格面部对照中，旧结果嘴线被肤色覆盖，新结果保留为棕色格，鼻子也更明显；并非恢复原图全部细节。全身52格中脸宽约8～10格，眼睛的多个高光、嘴型弯曲仍有明显信息损失。29等更小格数不承诺五官均可还原。
