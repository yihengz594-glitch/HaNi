# 目标模式实现与验收状态

更新：2026-10-04。当前为试用实现，未发布、未上传微信，不能视为最终视觉验收通过。

## 已实现

- 原模式默认保留；目标模式独立入口，所有尺寸共享新引擎。不得通过增加格数改善效果。
- 服务端规范化目标模式版本，任务身份与旧模式分离；旧模式请求字段保持原样。
- 原生图像前景分析、像素网格识别、面积降采样、保边平滑和原图细线补采样。
- 区域颜色先简化，再匹配用户选定的真实 MARD 色板；使用感知颜色距离，无抖动。
- 输入类型与结构分析采用固定尺度，再投影到工作图；同一图片不会随画格尺寸切换策略。
- 中性灰区域与棕色等有色区域分开量化，避免衣服借用头发的棕色中心。
- 有肤色证据的区域与白色大区域分开量化；黑白漫画限制到所选色板内已有灰阶。
- 小连通块清理保护原图细节证据，受保护格的颜色误差变差时局部回退。
- 1～3 格小色块清理增加原图验证：豆色之间差异大时，只有原图区域平坦、无强边缘且替换损失有界才允许合并。
- 编辑、历史保存、PNG 导出和统计使用最终色号矩阵；两种模式均有测试。
- 目标模式请求拒绝没有对应模式/版本标识的旧服务端响应。

## 未达到的要求与风险

- 十二种类型只有传统图像启发式评分，非可靠语义识别；脸部候选可能误识别手、衣服、耳朵。
- 五张样例的跨尺寸策略变化已修复；但稳定策略不代表可靠语义识别，尚未实现真实语义层级。
- 抱枕女孩头发和衣服简化偏平，低尺寸眼睛与底部小猫细节仍需改善。
- 银猫的近中性毛发已不再使用 H14/H22 主色，100 格颜色数降到 15；MARD 中间灰仍可能有轻微冷调，不能承诺实体色板完全无色差。
- 分层诊断确认采样和区域量化保留了原图浅灰，色差主要受真实 MARD 色域限制；对比页保留“豆色匹配前”诊断图用于继续定位。
- 对比预览的 100 格结果可展开“豆色匹配前的区域颜色”，明确标记为诊断图；此图不是实际豆色图纸，不能用它替代最终色号结果证明完成。
- 感知距离不能补足实体豆色色板的全部色域，不能承诺与原图完全无色差。
- 全量测试不等于微信真机、线上鉴权/计费、实际上传或视觉验收。
- 当前原生导出验证为 PNG，不声称实现或验收了 PDF。
